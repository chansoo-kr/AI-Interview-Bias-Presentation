# 기계는 무엇을 보았는가
**AI 채용 편향에 관한 인터랙티브 전시** · 사회과 수행평가

전시장(다크 월 + 종이 작품) 컨셉의 단일 페이지 웹 전시입니다. 외부 라이브러리 없이 순수 HTML/CSS/JS로 제작했습니다.

## 전시 구성

| 전시실 | 주제 | 인터랙션 |
|---|---|---|
| 제1전시실 · 기록의 방 | 실제로 보도된 AI 채용 편향 사례 | 신문 지면 형태의 기사 카드를 눌러 전문 열람, 모든 기사에 원문 출처 링크 표기 |
| 제2전시실 · 기계의 방 | 편향의 발생 원리 | ① 학습 데이터 비율 슬라이더로 **편향 증폭** 시뮬레이션 ② **인과 / 상관** 도식 전환 및 변수별 해설 |
| 제3전시실 · 처방의 방 | 해결 방안 | ① **인적사항 마스킹** 실험대 ② **판단 근거** 의무 표시 ③ **일괄 비교 심사**(지원서를 한 번에 넣어 기준 고정) |

## 다루는 원인

1. AI가 **과거의 편향된 채용 기록**을 정답지로 학습한다 — 기울기를 물려받는 데 그치지 않고 증폭한다.
2. AI는 **인과가 아니라 상관**을 센다 — 이름·거주지·학교처럼 성과를 만들지 않는 신호를 합격의 원인으로 취급한다.

## 해결 방안

1. **가린다** — 성명·성별·나이·사진·주소·학교를 모델 입력 단계에서 제거하고, 대리 신호(proxy)까지 점검한다.
2. **이유를 남긴다** — 모든 판정에 채용 공고의 어떤 요건을 근거로 삼았는지 기록하고 열람·이의제기를 보장한다.
3. **한 번에 비교한다** — 지원서를 한 명씩 따로 채점하지 않고 하나의 요청에 모두 넣어 동일한 기준으로 비교한다. 순서 편향을 줄이기 위해 순서를 섞어 여러 번 돌린 뒤 평균을 낸다.
4. **정기 감사** / 5. **최종 결정은 사람이 한다**

## 출처

전시된 모든 사례는 실제 보도·판결·연구에 근거하며, 각 기사 카드와 페이지 하단 「출처 및 참고자료」에 원문 링크를 표기했습니다. 지면은 원 보도의 사실관계를 바탕으로 전시용으로 재구성한 것입니다.
